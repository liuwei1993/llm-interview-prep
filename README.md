# llm-interview-prep

大模型八股 · 分课时学习包

从《大模型应用/算法学习路线+八股+面试实战》按**一课约一小时**拆开，方便按目录推进。桌面上的长文源文件还在，本目录只用于系统学习。

| 项目 | 数量 |
|------|------|
| 总课时 | **132** |
| 合计学时 | 约 **115** 小时 |
| 切分方式 | 默认按原书二级标题；超过约 1.3 万字再按三级/四级切开 |

## 怎么用

1. 打开本文件，按「推荐顺序」而不是按文件夹编号硬背。
2. **一次只学一课**（顶部有预计时间）。读完合上，用自己的话讲一遍，并想一个能套进项目的例子。
3. 超过 1 小时还没读完：先抓面试题和加粗结论，细节第二天补。

## 推荐顺序

**阶段一 · 应用起手（入行 / 应用岗）**

1. [`00-指南`](./00-指南/README.md) 路线、岗位、学习顺序（更新记录可略读）
2. [`07-AI素养` 第 1 课 提示词工程](./07-AI素养/01-AI 通用素养 · 1. 提示词工程.md)　先读这一课，再进入 RAG / Agent
3. [`03-RAG`](./03-RAG/README.md) 总览 → 切块 → 召回 → 面试题
4. [`04-Agent`](./04-Agent/README.md) 框架、MCP（含新技术与趋势）、记忆、Multi-Agent、ReAct、评测、场景题、健壮性  
   阶段一先跳过开源深读：17–31（OpenClaw / Hermes / PI）和 36–38（DeepSeek Harness）
5. [`07-AI素养`](./07-AI素养/README.md) 其余用法课：SKILL、Harness、Claude Code 用法、Vibe Coding  
   源码课 11–18 放到阶段二
6. [`01-项目实战`](./01-项目实战/README.md) 把项目跑通并写进简历
7. [`09-面试准备`](./09-面试准备/README.md) 自我介绍、简历六步写法、ForgePilot 面试前突击

**阶段二 · 加分 / 往算法靠**

1. [`02-LLM结构`](./02-LLM结构/README.md)（含 Jev）+ [`05-微调推理`](./05-微调推理/README.md)
2. `04-Agent` 17–31、36–38：PI、OpenClaw、Hermes、DeepSeek Harness，跟项目一起看。2026-10 作者更正：OpenClaw / Hermes 考察变少，优先 Claude Code、Pi-Agent、DeepSeek Harness、Codex
3. `07-AI素养` 11–18：Claude Code 源码
4. [`06-后端`](./06-后端/README.md) 按需，不是入行门槛
5. [`08-论文算法`](./08-论文算法/README.md)
6. `01-项目实战` 里的后训练项目

**阶段三 · 刷真题**

[`10-面试实战`](./10-面试实战/README.md) 按公司一场一课，碰到链接再跳回对应八股。最后一场是 2026.08 阿里淘天秋招。
