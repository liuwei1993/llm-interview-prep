## **2026.06 米连科技**

这个面经是我自己社招的面试内容。其实也没什么好说的，整体聊了快90分钟。面试官一开始让我画项目流程图，一边画一边讲，我觉得也没什么难的，围绕项目，大模型的技术讲的也挺好。

我觉得整体答得也很不错，最后一面挂，反馈是我们需要一个更资深一点的人选。

本身面试也不难，暂时没有总结答案。大家先自己看看吧（有需要我会复盘，没复盘答案肯定说明我总结了更有价值的其他内容，面经系列也会持续更新的）

### 岗位介绍

工作职责

1. 负责集团 AI Agent 整体技术架构规划、整体方案设计，搭建集团 Agent 平台与底层技术体系。
2. 主导大模型、RAG、智能体编排、多智能体协同体系建设，负责技术选型、架构落地与迭代优化。
3. 结合米连社交产品矩阵，落地虚拟人、智能互动、新项目等 AI Agent 业务场景。
4. 统筹 AI Agent 项目全生命周期管理，从 0 到 1 立项、研发、上线、数据复盘与规模化复制。
5. 负责 AI 算法、工程、产品团队搭建与管理，制定人才培养、目标拆解与绩效考核机制。
职位要求

1. 本科及以上学历，3 年以上 AI 大模型 / NLP / agent系统架构经验
2. 精通 AI Agent 核心架构，熟练掌握规划、记忆、RAG、工具调用、多智能体协同等核心能力。
3. 具备大模型微调、Prompt 工程、推理优化、LLM 工程化部署及向量数据库落地实战经验。
4. 熟悉互联网产品TOC业务逻辑，能把 AI 能力转化为业务指标。
5. 具备大型高并发系统架构设计、跨部门项目推进、技术攻坚与结果交付能力。
7. 有全局战略思维，领导力强，抗压性高，能适配集团业务快速迭代与全球化布局需求。
