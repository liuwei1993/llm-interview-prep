## 怎么用

1. **先按方向刷**：每个方向通读一遍，遇到答不上来的题标记出来。
2. **自测模式**：只看「题目」，用嘴讲一遍，再对「答题要点」查漏。
3. **结合岗位**：应用/Agent 岗重点刷 1–6；做检索/知识库重点刷 7–8；往算法靠再刷 9。
4. **串成故事**：面试时把「流程可控（状态机）→ 入口分流（路由）→ 持续变强（飞轮）」这类主线串起来讲，比单点回答更显体系感。
