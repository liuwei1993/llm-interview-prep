## 一句话结论

知乎直答是以 **RAG 为主干**、叠加 **多智能体 / Plan×RAG**、依托 **知乎社区质量信号 + 专业论文库**、并用 **ZhiLight / vLLM / SGLang** 等推理栈支撑的 AI 搜索产品；模型侧从「知海图 AI」演进到接入 **DeepSeek-R1** 等强推理模型。

## 调研范围与局限

- **依据**：知乎官方活动/沙龙分享、DataFunTalk 技术文章转载、量子位等媒体报道、ZhiLight 开源仓库、知乎开放平台文档等。
- **非内部代码审计**：未公开的中间件选型、索引具体引擎、线上拓扑等，报告中标注为「公开未披露」或「合理推断」。
- **调研日期**：2026-10-26
